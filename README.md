# 整车费用分摊台

- 行业:物流
- 技术栈:Vue3、Vite、TypeScript、Pinia、Element Plus
- 启动:`npm install && npm run dev`
- 构建:`npm run build`

由原“物流费用试算器”扩展而来,解决整车一张总运费在多个收货人之间结算对不上账的问题。
数据默认保存在浏览器 localStorage,重开页面后仍可按线路核账。

## 分摊规则

1. 一张报价登记:运输线路、总运费、各收货人的实际重量(kg)与体积(m³)。
2. 体积按每立方米 200 公斤折算,计费重 = max(实际重量, 体积折算重)。
3. 按各收货人计费重占比拆分总运费,金额算到分:每行先向下取整,尾差全部补给计费重最大的收货人(并列取第一位)。
4. 每行的分摊金额合计必然等于总运费,页面合计行可直接核对。

## 业务流程

- **改重量先重算**:工作台里任何重量/体积改动都会使结果失效,必须点「重算」后才能「确认分摊」。
- **已确认不可改,只能复制新版本**:确认后的分摊单是快照;「复制新版本」生成草稿,改完重算再确认。
- **同一报价只留一张当前单**:再次确认时旧当前单自动转为「历史」,旧单仍可在历史区查询。
- **撤回未发出的版本**:当前单未发出时可撤回,撤回后上一版重新成为当前结果;一旦「标记已发出」不可撤回。
- **按线路核账**:分摊单面板顶部按线路汇总报价数、已分摊数、登记运费、已分摊运费与待分摊金额。

## 目录结构(资料 / 规则 / 存取 / 页面分开)

```
src/
  types.ts                 资料模型(报价、收货人、分摊单、草稿)
  data/seed.ts             首次打开的演示资料
  domain/allocation.ts     分摊规则(纯函数:折算、计费重、按比拆分到分、尾差)
  domain/sheetBook.ts      版本链规则(确认 / 撤回 / 发出,纯函数)
  storage/repository.ts    localStorage 存取
  store.ts                 状态与动作(粘合层,页面只调这里)
  utils/format.ts          金额、重量、时间展示格式化
  components/
    QuoteForm.vue          报价登记
    QuoteList.vue          报价列表
    DraftPanel.vue         分摊工作台(改重量→重算→确认)
    SheetBoard.vue         分摊单与按线路核账
  App.vue                  页面组装
```
